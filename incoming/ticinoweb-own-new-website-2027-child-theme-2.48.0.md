
- Software store, licenze: **l'elenco dei plugin in vendita va a Odoo da solo** (GestaClient → Plugin WordPress → Plugin)
  quando un plugin viene pubblicato, tolto o cestinato, e una volta al giorno; i plugin non più in vendita si spengono in
  Odoo, le loro licenze restano valide. Perché: un plugin nuovo in vendita compariva in Odoo solo al primo ordine.
  Pulsante «Manda ora l'elenco dei plugin a Odoo» con la data dell'ultimo invio in WooCommerce → Software Store, e
  `wp tw-store license-catalog`.
