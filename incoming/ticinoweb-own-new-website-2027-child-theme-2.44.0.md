
- Download di un'app desktop (es. GestABLE): nuovo box «Download app desktop» nell'editor della pagina, con due campi (nome dell'app e repository delle release su GitHub). Sotto il titolo di una pagina Servizio compare la sezione «Scarica …» con un pulsante per sistema, la versione e la data dell'ultima release e la scritta «Gratis». Il file giusto (DMG per Mac con chip Apple o universale, installer Windows) viene scelto da solo dall'ultima release pubblicata: niente link da cambiare a ogni versione. I pulsanti puntano a un indirizzo fisso del sito (`/wp-json/ticinoweb/v1/app-download`) che rimanda al file dell'ultima versione, così funzionano anche con la pagina in cache. Ogni ora il tema rilegge GitHub e, se è uscita una versione nuova, svuota la cache di LiteSpeed. Un sistema senza file nella release (oggi Windows) è mostrato come «Presto in arrivo» e diventa scaricabile da solo quando la release contiene il suo installer. Il box verifica subito il repository e dice quale versione e quali file ha trovato. Dati strutturati `SoftwareApplication` (gratuita) sulla pagina. CSS caricato solo dove serve.
