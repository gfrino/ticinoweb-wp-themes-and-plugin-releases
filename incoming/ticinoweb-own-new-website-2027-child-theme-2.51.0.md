
- Menu principale: una voce di primo livello con la classe CSS `tw-menu-top` (Aspetto → Menu → Classi CSS) compare subito dopo «Shop», con accanto il suo logo che gira un po' al passaggio del mouse (niente animazione per chi ha chiesto meno movimento). Il logo è l'immagine della Libreria Media chiamata «<slug della pagina>-menu-logo» (es. `gestable-menu-logo.png`): per cambiarlo basta caricarne un'altra con quel nome. Usata per GestABLE, uscito dal pannello Shop.
