
- Software store: i **plugin a pagamento non hanno più lo zip nel repo pubblico** (sta in Odoo, GestaClient → Plugin
  WordPress → Versioni). Quando una release arriva senza zip, il negozio chiede a Odoo il link firmato, scarica lo zip,
  controlla che sia identico (SHA-256) e aggiorna il prodotto come prima; versione, novità e scheda restano dal repo
  pubblico. Perché: chiunque poteva scaricare gratis dal repo pubblico i plugin in vendita.
